Cerberus

Autonomous Software Repair & Patch Verification

Checks whether a patch, written by a developer or an AI, actually fixes the reported bug before it is accepted. An 11-stage pipeline reproduces the failure, applies the patch, reruns the tests and looks for regressions inside network-isolated Docker sandboxes. It runs as a FastAPI GitHub App that posts Check Runs.
